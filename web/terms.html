1. Penerimaan Syarat

Dengan menginstal atau menggunakan Bareuang ("Aplikasi"), kamu menyetujui Syarat ini. Jika tidak setuju, hapus instalasi Aplikasi.

2. Lisensi Penggunaan

Kami memberi lisensi pribadi, non-eksklusif, tidak dapat dipindahtangankan untuk menggunakan Bareuang di perangkat Android kamu. Lisensi ini bukan penjualan. Kamu tidak memperoleh hak kepemilikan atas Aplikasi.

Aplikasi berlisensi MIT untuk kode sumber di GitHub — lihat LICENSE. Penggunaan merek, logo, dan aset visual tetap milik pengembang.

3. Tanggung Jawab Pengguna

  • Kamu bertanggung jawab atas kebenaran data yang kamu input (nominal, tanggal, merchant, wallet).
  • Impor CSV dan Scan Struk OCR adalah alat bantu — selalu periksa kembali hasil impor/scan sebelum menyimpan.
  • Kamu wajib menjaga keamanan perangkat (kunci layar, tidak root yang membahayakan sandbox).
  • Usia: kamu menyatakan berusia minimal 13 tahun atau menggunakan di bawah pengawasan wali.

4. Disclaimer — Bukan Nasihat Keuangan

Penting untuk app keuangan — baca bagian ini.

Bareuang bukan penasihat keuangan, bukan bank, bukan dompet elektronik. Fitur Financial Runway, burn rate, Estimated Death Day, dan analitik adalah estimasi matematis berdasarkan data historis yang kamu input — bukan prediksi yang dijamin, bukan rekomendasi investasi, tabungan, pinjaman, atau keputusan keuangan.

  • Estimasi runway bisa meleset jika pola pengeluaran berubah, ada transaksi yang belum dicatat, atau data impor tidak lengkap.
  • Jangan jadikan angka di Bareuang sebagai satu-satunya dasar untuk keputusan keuangan penting. Konsultasikan ke profesional berlisensi bila diperlukan.
  • Kami tidak bertanggung jawab atas keputusan keuangan, kerugian, atau kehilangan peluang yang timbul dari penggunaan estimasi tersebut.

5. Backup, Restore & Kehilangan Data

Bareuang menyimpan data hanya lokal. Fitur Backup mengekspor file .json ke lokasi yang kamu pilih. Kamu bertanggung jawab menyimpan file backup di tempat aman.

  • Uninstall / Clear Data / reset pabrik akan menghapus semua data permanen jika tidak ada backup.
  • Kami tidak memiliki salinan data kamu dan tidak dapat memulihkan data tanpa file backup.
  • Impor CSV yang besar (>5MB) akan ditolak untuk menjaga stabilitas.
