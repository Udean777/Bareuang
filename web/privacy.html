1. Ringkasnya

Bareuang tidak mengumpulkan, tidak mengirim, dan tidak menjual data kamu. Semua data keuangan (transaksi, wallet, budget, goals, bills) disimpan lokal di HP kamu via Room Database. Tidak ada akun, tidak ada server, tidak ada analytics.

2. Data yang Kamu Masukkan — Tetap di HP

Data yang kamu input (nominal, kategori, merchant, foto struk untuk OCR) hanya diproses on-device. OCR struk memakai Google ML Kit Text Recognition (on-device) — gambar struk tidak diupload ke internet.

  • Tidak ada pengumpulan email, nama, lokasi, kontak, atau identifier iklan.
  • Tidak ada SDK analytics, crash reporter, atau tracker pihak ketiga.
  • Tidak ada sinkronisasi cloud.

Untuk kebutuhan Google Play Data Safety, kami mendeklarasikan: No data collected, No data shared.

3. 100% Offline — Tanpa Izin Internet

Aplikasi Bareuang tidak mendeklarasikan permission INTERNET. Secara teknis tidak bisa mengirim data keluar, bahkan jika mau. Backup & Restore dilakukan via file .json yang kamu simpan sendiri (mis. ke Files/Drive manual — di luar kendali aplikasi).

4. Izin yang Diminta

  • CAMERA — hanya untuk foto struk (OCR). Dipakai saat kamu menekan "Scan Struk". Tidak dipakai di background.
  • POST_NOTIFICATIONS (Android 13+) — hanya untuk pengingat tagihan H-3 (WorkManager lokal). Tidak ada push dari server.
  • Storage (via SAF) — hanya saat kamu memilih file CSV untuk impor atau memilih lokasi backup/restore.

Tidak ada izin lokasi, mikrofon, kontak, atau SMS.

5. Anak di Bawah Umur

Bareuang tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data anak secara sengaja. Karena tidak ada pengumpulan data sama sekali, tidak ada pemrosesan khusus.

6. Retensi & Cara Hapus Data

Data tersimpan selama aplikasi terinstal. Kamu bisa hapus kapan saja:

  • Di aplikasi: Pengaturan → Hapus Data
  • Di Android: Settings → Apps → Bareuang → Storage → Clear Data
  • Uninstall aplikasi — semua data lokal terhapus permanen (kecuali file backup .json yang kamu ekspor manual).

Karena tidak ada server, kami tidak bisa menghapus data untuk kamu — kamu yang memegang kendali penuh.

7. Cookies (Situs Web)

Situs bareuang.app adalah situs statis. Tidak menggunakan cookie, tidak ada analytics, tidak ada tracker iklan. Jika di masa depan ditambahkan analytics minimal (mis. privacy-friendly), kebijakan ini akan diperbarui dan banner persetujuan akan ditampilkan.

8. Keamanan

Data disimpan di storage privat aplikasi (sandbox Android). Keamanan bergantung pada keamanan perangkat kamu (kunci layar, enkripsi device). Kami menerapkan validasi input dan guard saldo/budget di level use-case, namun tidak ada enkripsi tambahan di database lokal pada v1.

9. Perubahan Kebijakan

Jika kebijakan berubah, tanggal "Terakhir diperbarui" di atas akan diganti dan perubahan penting akan dicantumkan di halaman ini serta di catatan rilis Play Store. Penggunaan berkelanjutan setelah perubahan dianggap menyetujui versi terbaru.
